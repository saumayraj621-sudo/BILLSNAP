# BillSnap

BillSnap is a web application that converts multiple bill images into a single compressed PDF (under 2MB).

## Features
- Upload multiple bill images
- Drag & Drop support
- Auto PDF generation
- PDF compression
- Preview before download
- Responsive UI

## Tech Stack
- HTML
- CSS
- JavaScript
- jsPDF
- OpenCV.js
